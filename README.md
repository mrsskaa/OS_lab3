# Лабораторная работа № 3

**Вариант 17. Поиск минимума и максимума в массиве.**

Программа на C выполняет параллельный поиск с помощью POSIX-потоков (`pthread`). Массив разделяется на части, результаты поиска объединяются после завершения потоков.

## Требования

Ubuntu, компилятор C с поддержкой C11 и CMake 3.16 или выше.

## Сборка

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

## Запуск

```bash
./build/os_lab3 -n 1000000 -t 4
```

- `-n` — количество элементов массива.
- `-t` — максимальное число потоков, включая главный.
- `-d` — необязательный режим вывода PID и TID с паузой на 10 секунд.

Параметры передаются в порядке `-n`, `-t`, затем необязательный `-d`. Размер массива и число потоков должны быть положительными.

Программа создаёт массив псевдослучайных чисел и выводит минимум, максимум и время поиска в секундах. При размере меньше 30 элементов также выводится массив. Для измерения времени используется запуск без `-d`.

## Структура проекта

- `src/main.c` — обработка параметров, создание массива и измерение времени.
- `src/minmax.c` — последовательный и многопоточный поиск.
- `src/minmax.h` — объявления функции поиска и структуры результата.
